# KU Design Job Leads

The public copy of the KU design internship and job board: https://titusmith.github.io/ku-design-internships/

- `index.html`: the student site, synced automatically from the board where it's edited. Don't edit it by hand; changes get overwritten.
- `tools/sync_site.py`: makes `index.html` from the board, leaving out the Suggested queue.
- `scout/`: the Friday scout's instructions, watch list, memory and log.
